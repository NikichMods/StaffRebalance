# Fire Combo Boundary 01

**Игровой read-only PASS для обычных Fire 1/2/3.** Проба отключена. Production gate — BLOCKED.

Cooked [карта источников](STAFF_ELEMENTAL_COVERAGE_01.md#карта-источников) даёт один `fire object` основного болта на обычный Fire-шаг. [Fire 01/02](COMBAT_OBSERVATION_01.md#результат-fire-прогона-01) и [Fire A/B](FIRE_RATE_PROBE_01.md) уже установили происхождение сферы и возможность ослабления. Здесь нужен единый упорядоченный след, чтобы проверить фактическое число болтов внутри каждого исполнения, различить повтор и остановку после atk2, а также связать сферы с болтами независимо от текущего skill. Адаптация [Astral boundary probe](ASTRAL_COMBO_BOUNDARY_01.md) даёт это четырьмя точными хуками без нового механизма атрибуции.

- Native `BeginDoSkill/EndDoSkill` pre/post фиксируют `pending` и `doing` одного проверенного anim локальной Хильды.
- Script post `ReceiveBeginPlay` пишет точный Fire-класс, ключ, CharacterOwner и `GameGlobal.GetDoingSkill` на основном болте. Для сферы проверяются точный ключ `hilda_staff_bolt_fire_explosion`, класс и ключ Actor Owner и совпадение обоих CharacterOwner с Хильдой. Связь восстанавливается по строковой идентичности родительского болта, даже если сфера появилась после End. Текущий skill на сфере служит только диагностикой.
- F5 начинает захват или отмечает новый эпизод. F7 снимает оба script hook и запрашивает снятие двух native pre/post пар. Одна контрольная атака после F7 даёт UE4SS завершить отложенное снятие. Все операции ограничены чтением и диагностикой.

## Прогон

1. Прогреть оба класса одиночным Fire-выстрелом с видимым взрывом. Дождаться конца анимации и взрыва.
2. F5, полное обычное комбо 1→2→3. После его окончания F5, ещё одно полное комбо. Использовать обычные атаки, по возможности дать болтам столкнуться с врагом или поверхностью и взорваться.
3. После завершения F5, серия 1→2. Дождаться окончания второго шага, затем выполнить один новый первый выстрел без метки. Промахи допустимы, но для проверки цепочки нужен хотя бы один наблюдённый взрыв для каждого шага.
4. F7, один контрольный выстрел, дождаться окончания анимации и закрыть игру. Проверить закрытый лог, физическое снятие четырёх native callbacks и двух script hooks, отключить только эту пробу.

PASS требует одного болта на каждое наблюдённое обычное исполнение, точных имён skill и однозначной связи наблюдённых сфер с этими болтами. Отсутствующий взрыв отмечается отдельно. Спецатаки, принудительные прерывания и возможность появления сферы после End считаются проверенными только при наличии соответствующих событий.

Точные имена: `hilda_staff_atk1_idle_fire`, `hilda_staff_atk1_fire`, `hilda_staff_atk2_fire`, `hilda_staff_atk3_fire`. После прекращения на atk2 пришёл новый Begin atk1 без промежуточного atk3.
- Все девять сфер однозначно совпали с родительскими болтами по Actor Owner и локальной Хильде. В обеих полных сериях сфера первого шага возникла уже после его End, когда `GetDoingSkill` сообщал atk2 (seq 14 и 35). Поэтому режим будущей узкой интеграции следует связывать с основным болтом при его BeginPlay и читать у сферы по точному родителю, включая время после окончания skill. Текущий skill сферы для этого непригоден.
- PASS ограничен обычными шагами 1/2/3. Спецатаки, внешние прерывания, изменение DamageRate и дебет в этой пробе не испытывались. Имена спецатак не входят в проверенный допуск.
- F7 сняла script ID 14 и 15. Контрольный выстрел завершил снятие обеих native pre/post пар (10–13). После STOP новых наблюдений нет (строки 794–800). Маркер пробы отключён, `mods.txt` и остальные маркеры совпали.
