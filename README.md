# StaffRebalance

Экспериментальный проект мода для **Asterigos: Curse of the Stars** (PC), который превращает посох в сильное, но ограниченное средство дальнего боя, дополняющее любое оружие ближнего боя.

**Состояние:** организационная основа проекта подготовлена; техническое исследование ещё не начато. Готового мода, установочного пакета и принятой версии пока нет. Никаких изменений игры этот репозиторий сейчас не содержит.

## Задумка

- Посох использует отдельный ограниченный запас зарядов. Каждая **фактически выполненная** атака посоха тратит максимум один заряд вне зависимости от попадания; последовательные действия комбо считаются отдельно.
- Один ввод, порождающий несколько снарядов, AoE или отложенные попадания, — одно расходование. Для прицельных Charged Rays один выполненный выстрел тоже тратит один заряд; вход в прицеливание — нет.
- С зарядом сохраняется штатный боевой урон. Без зарядов посох продолжает работать, но наносит существенно меньший **боевой урон**. Это не должно ломать разрушение/активацию объектов мира.
- Заряды пополняются за результативное использование оружия ближнего боя. Запас не сбрасывается автоматически между столкновениями и полностью восстанавливается при **отдыхе** у Conduit.
- AP/APR, активные навыки, управление, автонаведение, дальность, контроль, статусы и другие неуронные свойства не меняются. Локальная тревога противников — **отдельное исследование**, не обязательное условие работы этого мода.

Количество зарядов (например, пять), скорость пополнения (например, один за melee-атаку) и множитель слабого выстрела (например, 10%) — **не утверждённые тестовые ориентиры**.
