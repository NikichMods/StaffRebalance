# StaffRebalance

Исследовательский проект мода для **Asterigos: Curse of the Stars** (PC). Цель — превратить посох в сильное, но ограниченное дальнобойное дополнение к любому оружию ближнего боя.

**Статус на 2026-11-07:** обновлён продуктовый дизайн; техническая реализация **BLOCKED** до доказательства безопасного штатного способа менять коэффициент силы атаки и начислять энергию за melee-попадание. Готового мода, установочного пакета, версии и принятой сборки нет. Репозиторий не содержит работающего изменения боевой системы игры.

## Задумка

- Отдельный ограниченный **магический резерв**, не совпадающий со штатными AP/APR. Сильные выстрелы посоха расходуют его **при фактическом выполнении атаки** — даже при промахе. Прицеливание, удержание и отмена до выстрела не расходуют запас.
- Каждое выполненное действие оплачивается **один раз**, независимо от числа целей, попаданий и дочерних эффектов. Когда энергии на сильный выстрел не хватает, посох стреляет в ослабленном режиме, не уходя в отрицательный резерв. Частичное усиление для первого прототипа не требуется.
- Сила атаки по возможности меняется через **штатный параметр урона**, с сохранением расчёта игрой. Допустимо уменьшение повреждения частей тела, зависимых от величины урона реакций, нагрузки на защиту и числового урона по разрушаемым объектам; отдельные статусы, контроль и другие неуронные параметры напрямую не меняются.
- **Подтверждённые попадания melee-оружием по врагу** возвращают энергию, даже если защита поглотила HP-урон. Промахи и удары по окружению её не дают. Разные награды для быстрых/тяжёлых ударов — возможная настройка, не утверждённые числа.
- Резерв сохраняется между столкновениями; настоящий **отдых у Conduit** заполняет его полностью. Меню и телепортация не считаются отдыхом.
- Требуется заметный для игрока контраст между сильным и слабым посохом. Желательна простая, наглядная шкала энергии. Точная стоимость выстрела, величина награды, слабый множитель и HUD ещё не определены.

**Важно:** это принятый *игровой дизайн*, а не подтверждение доступности подходящего UE4SS/API-хука. В частности, запись в DamageRate может быть перезаписана штатной логикой некоторых талантов; вклад дочерних эффектов нужно оценивать по фактическому снижению силы атак.
